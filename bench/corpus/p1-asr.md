# 음성 인식 파이프라인의 구성 요소

음성 인식 시스템은 크게 네 계층으로 나뉜다. 첫째는 전처리 계층이며, 입력 파형에서 잡음을 걷어내고 표본율을 통일한다. 여기서 표본율이 어긋나면 이후 모든 시간축이 함께 밀리므로, 헤더에 적힌 값을 그대로 믿지 말고 디코더를 거쳐 실제 표본율을 확인해야 한다.

둘째는 특징 추출 계층이다. 파형을 짧은 창으로 잘라 스펙트럼을 구하고, 멜 필터뱅크를 통과시켜 차원을 줄인다. 창 길이와 이동 간격은 두 개의 파라미터로 노출되는데, 이 값이 모델 학습 당시와 다르면 추론 품질이 눈에 띄게 나빠진다. 그래서 학습 설정과 추론 설정을 한 파일에서 함께 관리하는 편이 안전하다.

셋째는 음향 모델 계층이다. 특징 벡터를 받아 음소나 자소 단위의 확률 분포를 산출한다. 최근에는 인코더와 디코더를 한 번에 학습하는 구조가 널리 채택되었고, 별도의 발음 사전 없이도 문자열을 바로 내놓는다. 다만 이 구조는 학습 코퍼스에 없던 고유명사에서 약하다. 표기가 엉뚱하게 바뀌거나, 소리가 비슷한 다른 단어로 대체되는 경우가 잦다.

넷째는 후처리 계층이다. 숫자와 단위를 표기 규정에 맞춰 정규화하고, 문장 부호를 복원한다. 이 단계는 평가 지표를 크게 흔들기 때문에, 지표를 비교할 때는 후처리 조건을 반드시 같이 적어야 한다. 같은 모델이라도 후처리를 벗겨내면 오류율이 몇 배로 커지는 일이 흔하다.

평가는 보통 문자 오류율과 단어 오류율 두 가지로 한다. 두 지표는 언어에 따라 서로 다른 이야기를 하므로, 한국어에서는 문자 오류율을 기본으로 두고 단어 오류율을 보조로 쓰는 편이 낫다. 세그먼트 경계가 정답과 겹치지 않으면 정렬 과정에서 손실이 과다하게 계산되므로, 채점 전에 경계를 통째로 다시 맞추는 절차가 필요하다.

운영 단계에서 자주 겹치는 요구는 두 가지다. 하나는 첫 응답까지의 지연을 줄이라는 것이고, 다른 하나는 긴 발화에서도 정확도를 유지하라는 것이다. 두 요구는 서로 상충하므로, 구간을 짧게 끊어 부분 결과를 먼저 내보내고 뒤에서 평균적으로 보정하는 방식이 자리를 잡았다. 이때 부분 결과를 갱신하는 빈도가 지나치게 높으면 화면이 계속 흔들려 사용자 경험을 해친다.
